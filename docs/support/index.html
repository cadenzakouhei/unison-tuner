よくあるご質問

マイクの音は録音・保存されますか?

されません。マイクから取得した音声は端末内でリアルタイムに解析されるのみで、録音・保存・外部送信は一切行っていません。

スペクトログラムが動きません

画面右上の「MIC ON」ボタンがオンになっているか、また設定アプリで本アプリのマイクへのアクセスが許可されているかをご確認ください。

対応しているiOSのバージョンは?

最新のiOS上での動作を前提に開発しています。古いバージョンでの不具合が見られた場合はサポート先までご連絡ください。
